# Used-Car-Price-Prediction
Machine Learning project to predict used car prices using .Python ,Pandas ,NumPy ,Matplotlib ,Scikit-learn and Linear Regression

This is a Machine Learning project I worked on using Python. The main aim was to predict the price of a used car based on some of its details, such as brand, year, kilometres driven, fuel type and transmission.
I started by cleaning the data and understanding it through graphs and analysis. After that, I used Linear Regression to train a model and predict car prices.

### Tools I Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

### Model Result
- R² Score: 95.2%
- MAE: 0.36 lakh

### What I Learned
This project gave me a better understanding of how Machine Learning works in practice. I got to work with data, prepare it for training and see how a model makes predictions.
